# Terror Images Sample / テラー画像サンプル

This folder contains empty placeholder files showing the expected image filenames.
このフォルダには、必要な画像ファイル名を示す空のプレースホルダーファイルが含まれています。

## How to use / 使用方法

### English

1. Copy this entire `images_sample` folder to where `ToNStatTool.exe` is located
2. Rename the copied folder to `images`
3. Replace each empty `.png` file with the actual terror image

### 日本語

1. この `images_sample` フォルダを `ToNStatTool.exe` がある場所にコピーする
2. コピーしたフォルダ名を `images` に変更する
3. 各空の `.png` ファイルを実際のテラー画像に置き換える

## Notes / 注意事項

- Images must have the same filename as the empty placeholder files
  画像は空のプレースホルダーファイルと同じファイル名にしてください

- Filenames are case-insensitive (e.g., `Baldi.png` = `baldi.png`)
  ファイル名の大文字小文字は区別されません

- Supported formats: PNG, JPG, JPEG, GIF, BMP
  対応形式: PNG, JPG, JPEG, GIF, BMP

- Image files are not included due to copyright restrictions
  著作権の関係で画像ファイルは含まれていません

- You don't need all images - only replace the ones you want to display
  すべての画像は必要ありません - 表示したいものだけ置き換えてください

## Filename conversion rules / ファイル名変換ルール

Terror names are converted to filenames by replacing any character that is NOT `a-z`, `A-Z`, `0-9`, or `_` with an underscore `_`.

テラー名は、`a-z`, `A-Z`, `0-9`, `_` 以外のすべての文字がアンダースコア `_` に置換されます。

### Examples / 例

| Terror Name | Filename |
|-------------|----------|
| Dr. Tox | `Dr__Tox.png` |
| MR.MEGA | `MR_MEGA.png` |
| S.O.S | `S_O_S.png` |
| [CENSORED] | `_CENSORED_.png` |
| ,D@;Q7Y | `_D__Q7Y.png` |

このフォルダには **192** 個のプレースホルダーファイルが含まれています。
